# AI Control Pane

This folder turns the approved product plan into implementation-ready product artifacts for a first build.

## Contents
- `mvp-definition.md`: the first persona, the first workflow, success criteria, and explicit MVP boundaries.
- `wireframes.md`: low-fidelity wireframes for the main dashboard, task detail page, approval inbox, and policy editor.
- `integrations.md`: the initial systems to integrate, the minimum data needed from each one, and rollout priorities.
- `SIG-5-design-decisions.md`: SIG-5 settings UI goals, WCAG-oriented review evidence, and issue traceability notes.
- `SIG-7-design-decisions.md`: SIG-7 frontend shell and evidence-panel accessibility decisions.

## Recommended Reading Order
1. Read `mvp-definition.md` to understand who the first version is for.
2. Read `wireframes.md` to see how the core surfaces support that workflow.
3. Read `integrations.md` to understand the external systems required to make the workflow real.
